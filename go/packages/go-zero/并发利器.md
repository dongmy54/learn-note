### MapReduce
场景：一批数据做处理,且要汇总结果

1. 其中一个产生错误，则立即返回，汇总值为空
2. 在第二步可以选择
   - cancel 整个过程结束
   - 是否继续Write,如果不继续write则本item不会流转第三步，其它item步影响
3. 在需要适当耗时的场景下，使用此种方式才有效果

```go
func CheckUids(uids []int64) ([]int64, error) {
	// 适合一批数据，并发处理，且要汇总结果
	// 1.其中一个产生错误，则立即返回，汇总值为空
	result, err := mr.MapReduce(func(source chan<- int64) {
		for _, uid := range uids {
			source <- uid
		}
	}, func(uid int64, writer mr.Writer[int64], cancel func(error)) {
		ok, err := Check(uid)
		if ok {
			writer.Write(uid) // 如果有效则传递到下一环节
		} else {
			cancel(err) // 如果失败则取消 取消会导致整个map流失败，返回错误 且 最终结果为空
		}
	}, func(pipe <-chan int64, writer mr.Writer[[]int64], cancel func(error)) {
		var result []int64
		for uid := range pipe {
			result = append(result, uid)
		}
		writer.Write(result)
	})

	return result, err
}

func Check(uid int64) (bool, error) {
	time.Sleep(time.Second * 1) // 模拟耗费时间

	if uid == 2 {
		return false, errors.New("发生错误")
	}
	return true, nil
}
```

### Finish
场景：多任务并发处理，如果其中一个报错则立即返回
比如：一个api中要同时调用多rpc的场景

1. 其中一个产生错误，则立即返回,返回值为error
2. Finish适合幂等的情况，发生error
   - 已执行完的不管
   - 未执行完的立即取消
3. 多函数执行无顺序

```go
err := mr.Finish(func() error {
		fmt.Println("=========啦啦啦1======")
		return nil
	},
		func() error {
			fmt.Println("=========啦啦啦2======")
			return errors.New("发生失败啦")
		},
		func() error {
			time.Sleep(time.Second * 2)
			fmt.Println("=========啦啦啦3======")
			return nil
		},
	)
```

### Parallel
场景：和Finish类型，但不关心错误；
PS：即使某个发生错误，其它任务也继续执行

```go
fx.Parallel(func() {
		fmt.Println("=======1=======")
	},
		func() {
			fmt.Println("=======2=======")
		},
		func() {
			fmt.Println("=======3=======")
		},
	)
```

### ForEach
场景：
1. 遍历处理，不关心处理结果（无返回值）
2. 每个item都按照相同的方式做处理

```go
type Task struct {
}

func (t *Task) Run() error {
	time.Sleep(time.Second * 1)
	fmt.Println("执行任务")
	return nil
}

tasks := []Task{}
for i := 0; i < 10; i++ {
	tasks = append(tasks, Task{})
}

mr.ForEach(func(source chan<- Task) {
		for _, task := range tasks {
			source <- task
		}
	}, func(task Task) {
		err := task.Run()
		if err != nil {
			fmt.Println("发生错误", err)
		}
	})
```
